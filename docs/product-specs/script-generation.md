# 발표 대본 생성

## 사용자 시나리오

1. 사용자가 발표용 PPT 파일을 업로드한다.
2. 서버가 슬라이드별 텍스트와 발표 주제/목차 키워드를 추출한다. (`POST /api/ppt/extract`)
3. 사용자가 발표 시간(분)과 스타일(예: "신뢰감을 주는 아나운서 스타일")을 지정하면, 슬라이드별 구어체 대본이 자동 생성된다. (`POST /api/script/full`)
4. 특정 슬라이드의 대본이 마음에 들지 않으면, 피드백 텍스트를 입력해 해당 슬라이드만 다시 생성할 수 있다. (`POST /api/script/partial`)

## 현재 구현 상태

| 단계 | 엔드포인트 | 상태 |
|---|---|---|
| PPT 구조화 추출 | `POST /api/ppt/extract` | 구현됨 |
| 전체 대본 생성 | `POST /api/script/full` | 구현됨 (HyperCLOVA X) |
| 부분 재생성 | `POST /api/script/partial` | 구현됨 (HyperCLOVA X) |

## 알려진 제약

- 대본이 저장되지 않습니다. 매 요청이 stateless이며, 새로고침하면 생성 결과가 사라집니다. 히스토리/이어쓰기 기능을 만들려면 영속성 계층이 먼저 필요합니다 ([docs/generated/db-schema.md](../generated/db-schema.md) 참고).
- `PptExtractor`의 주제/키워드 추출은 "목차/index/agenda 같은 단어가 나오면 그 다음 텍스트를 키워드로 본다"는 휴리스틱이라, 목차 슬라이드가 없는 PPT에서는 품질이 떨어질 수 있습니다.
- 대본 스타일(`style`)은 자유 텍스트라 사용자마다 표현이 제각각입니다. 프론트에서 스타일 프리셋(예: 격식체/친근체/아나운서체)을 선택지로 제공하는 것을 권장합니다.
