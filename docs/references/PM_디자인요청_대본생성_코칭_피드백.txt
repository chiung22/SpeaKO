================================================================================
        [디자인 요청] AI 대본 생성 흐름 / 발음 코칭 / 피드백 화면
                                                        - AI 서버 담당 드림
================================================================================

안녕하세요! AI 서버 기능 구현이 거의 마무리되어, 화면 연결을 위해 디자인 확인을
요청드립니다. 아래 3개 화면의 디자인이 필요합니다.


--------------------------------------------------------------------------------
■ 왜 요청드리는지 (배경)
--------------------------------------------------------------------------------

AI 서버는 이미 아래 기능들을 전부 만들어 두었습니다.

  - PPT/PDF를 읽어서 발표 대본 자동 생성
  - 대본 수정 / 슬라이드 추가·삭제 / 특정 슬라이드만 다시 생성
  - 발음 주의 단어 추출 + 발음기호 (예: 발전 -> [발쩐])
  - 녹음 발음 평가 (정확도/유창성/완성도/종합점수)
  - AI 코칭 피드백 (총평 / 잘한 점 / 개선할 점 / 연습 팁)

즉 "데이터"는 다 나옵니다. 그런데 이 데이터를 **화면 어디에 어떻게 놓을지**를
정한 디자인이 현재 피그마에 없어서, 프론트엔드가 붙일 기준이 없는 상태입니다.

최근 피그마를 전체 내보내기 해보니 아래 화면들만 있었습니다.
  홈(Section 1~3) / 로그인 / 회원가입 / 마이페이지 / 설정 모달 4종
  / 디자인시스템 / 배너

이전 버전 피그마에는 "AI 대본 생성 흐름", "Coach View Page", "Feedback Page"가
있었는데 지금은 보이지 않습니다. 삭제되었거나 다른 페이지에 있는 것 같습니다.
해당 프레임을 다시 공유해 주시거나, 없다면 새로 그려주시면 감사하겠습니다.


================================================================================
【요청 1】 AI 대본 생성 흐름  (이전 피그마의 "AI 대본 생성 – 초기화면 제작 과정")
================================================================================

■ 어떤 화면인가
  사용자가 PPT를 올리고 조건을 입력해서 대본을 만들고, 결과를 다듬는 전체 흐름입니다.

■ 서버가 받는 값 (이미 구현됨)
  - 발표 자료   : PPT(.pptx) 또는 PDF 업로드   ※ 구버전 .ppt는 지원 안 됨
  - 발표 주제   : 필수
  - 발표 시간   : 분 단위 (예: 8분)
  - 대상(청중)  : 선택 (예: 교수님, 면접관, 초등학생)
  - 말투        : "격식체" 또는 "편안한 말투" 2가지
  - 추가 가이드라인 : 선택, 자유 입력

■ 서버가 돌려주는 값 (예시)
  {
    "slides": [
      { "slide_number": "1", "script": "안녕하십니까. 이번 SpeaKO 서비스 소개
                                        발표를 맡은 홍길동입니다. ..." },
      { "slide_number": "2", "script": "SpeaKO의 핵심 기능은 크게 두 가지입니다. ..." }
    ]
  }

■ 확인·결정이 필요한 부분

  (1) 생성 중 로딩 화면
      대본 생성에 20~30초 정도 걸립니다. 이 시간 동안 무엇을 보여줄지 확정이 필요합니다.
      - 안 A : 로딩 아이콘만 계속 돌리기 (현재 이 방식으로 협의됨)
      - 안 B : "분석 중 -> 구성 중 -> 대본 생성 중 -> 완료" 단계 표시
      - 안 C : 진행률 바 (예: 12/30 슬라이드 완료)
      => B나 C로 하시려면 서버 작업이 추가로 필요하니 미리 알려주세요.
         (지금은 A 기준으로 구현되어 있습니다)

  (2) 결과 화면 레이아웃 2종
      - PPT를 올린 경우  : 왼쪽에 슬라이드 목록, 오른쪽에 해당 슬라이드 대본
      - PPT가 없는 경우  : 전체 대본 하나를 텍스트 영역에 표시
      두 경우의 화면이 각각 필요합니다.

  (3) 편집 기능의 UI 위치
      아래 3가지가 서버에 이미 있습니다. 버튼을 어디에 둘지 정해주시면 됩니다.
      - 대본 수정 후 저장       (자동 저장인지, "저장" 버튼인지 결정 필요)
      - 슬라이드 추가 / 삭제    (추가 시 원하는 위치에 끼워넣기 가능)
      - 이 슬라이드만 다시 생성 (말투나 요구사항을 바꿔서 재생성 가능)

  (4) 슬라이드 미리보기(썸네일) 필요 여부
      ※ 중요합니다.
      서버는 PPT에서 "글자"만 뽑습니다. 슬라이드를 그림으로 만들어 주지 않습니다.
      결과 화면에 실제 슬라이드 이미지를 보여줄 계획이라면, 프론트에서 PPT를
      직접 렌더링해야 합니다. 미리보기가 꼭 필요한지 알려주세요.

【요청 2】 발음 코칭 화면  (이전 피그마의 "Coach View Page")
================================================================================

■ 어떤 화면인가
  완성된 대본에서 "발음을 조심해야 하는 단어"를 표시해주고, 사용자가 녹음하며
  연습하는 화면입니다.

■ 서버가 돌려주는 값 (실제 예시)
  {
    "words": [
      { "word": "발전", "phoneme": ["발쩐"], "category": "표기-발음불일치" },
      { "word": "준비", "phoneme": ["준비"], "category": "장단음" },
      { "word": "발음", "phoneme": ["바름"], "category": "연음" }
    ],
    "summary": { "장단음": 6, "연음": 1, "표기-발음불일치": 3 }
  }

  즉, 단어마다 아래 3종류 중 하나로 분류되어 나옵니다.
    - 장단음          : 소리 길이를 구분해야 하는 단어   (예: 준비)
    - 연음            : 받침이 뒤로 넘어가는 단어        (예: 발음 -> [바름])
    - 표기-발음불일치  : 쓰는 것과 읽는 것이 다른 단어    (예: 발전 -> [발쩐])

■ 확인·결정이 필요한 부분

  (1) 하이라이트 색상 3종
      위 3개 분류를 대본 안에서 각각 다른 색으로 표시할 예정입니다.
      색상과 범례(legend) 디자인이 필요합니다.

  (2) 발음기호 표기 방식
      "발전" 옆에 [발쩐] 을 어떻게 보여줄지 정해주세요.
      - 단어 위에 작게 표시 / 마우스 올리면 툴팁 / 옆에 괄호로 표시 등

  (3) "단어 목록" 탭
      대본 안 하이라이팅 말고, 주의 단어만 모아 보는 목록도 필요한지 확인 부탁드립니다.
      (이전 피그마에는 "대본 뷰어 / 단어 목록" 두 탭이 있었습니다)

  (4) 요약 카드
      summary 값(장단음 6, 연음 1, 표기-발음불일치 3)을 보여주는 영역이 필요합니다.

  (5) 녹음 UI 상태 4가지
      녹음 전 / 녹음 중 / 일시정지 / 완료(분석 중) 각각의 디자인이 필요합니다.
      - 녹음은 최대 4분, 파일 크기 10MB 제한입니다.
      - 사용자가 중간에 멈춰도 읽은 부분까지만 채점되므로,
        "어디까지 읽었는지" 사용자에게 물어볼 필요는 없습니다.

  (6) [예정] 단어 발음 듣기 버튼
      다음 주에 "정확한 발음을 소리로 들려주는 기능"을 연결할 예정입니다.
      단어 옆에 스피커 아이콘을 둘 자리를 미리 잡아주시면 좋겠습니다.

【요청 3】 평가 결과 / 피드백 화면  (이전 피그마의 "Feedback Page")
================================================================================

■ 어떤 화면인가
  녹음한 발표를 AI가 채점하고, 무엇을 고쳐야 하는지 알려주는 화면입니다.

■ 서버가 돌려주는 값 (실제 예시)

  (1) 점수 - 4가지가 나옵니다. 전부 소수점 1자리(0~100점)입니다.
      {
        "accuracy": 87.4,             // 정확도  - 발음이 얼마나 정확한지
        "fluency": 82.1,              // 유창성  - 끊김 없이 자연스러운지
        "completeness": 95.0,         // 완성도  - 대본을 얼마나 읽었는지
        "pronunciation_score": 84.3   // 종합 점수
      }

  (2) 원본 대본 vs 실제로 읽은 내용
      "reference_text"  : "메타버스를 소개합니다."      <- 원래 읽어야 했던 문장
      "recognized_text" : "메타버스를 소개함니다"        <- AI가 실제로 들은 문장

  (3) 단어별 결과
      [
        { "word": "발전",   "accuracy_score": 52.0, "error_type": "Mispronunciation" },
        { "word": "평가",   "accuracy_score": 98.0, "error_type": "None" },
        { "word": "생략단어", "accuracy_score": 0.0, "error_type": "Omission" }
      ]
        Mispronunciation = 잘못 발음함 / None = 정상 / Omission = 안 읽고 넘어감

  (4) AI 코칭 피드백 - 4개 항목으로 나옵니다 (실제 생성 예시)
      {
        "summary": "전반적으로 발음이 또렷합니다. 다만 몇몇 단어에서 실수가 있었습니다.",
        "strengths":     ["'평가'를 아주 정확하게 발음하셨습니다."],
        "improvements":  ["'발전'의 받침을 끝까지 발음하도록 주의하세요.",
                          "'실시간'에서 시옷 발음을 명확히 해주세요."],
        "practice_tips": ["거울 앞에서 입 모양을 확인하며 연습해 보세요.",
                          "녹음해서 본인 목소리를 다시 들어보세요."]
      }

■ 확인·결정이 필요한 부분

  (1) 총점 표시
      점수가 4개인데, 화면의 큰 "총점"에는 어떤 걸 쓸지 정해주세요.
      (종합 점수 pronunciation_score 를 쓰는 것을 추천드립니다)
      나머지 3개는 함께 보여줄지, 상세 화면에만 둘지도 알려주세요.

  (2) 점수대별 문구
      이전 디자인에는 "87점 - 훌륭해요!" 같은 문구가 있었습니다.
      점수 구간별 문구/이모지 기준을 정해주시면 그대로 반영하겠습니다.
      (예: 90점 이상 = 훌륭해요 / 70~89 = 좋아요 / 70 미만 = 조금 더 연습해요)

  (3) 원본 vs 인식 텍스트 비교
      두 문장을 좌우로 나란히 놓을지, 위아래로 놓을지 정해주세요.
      또한 다르게 읽은 부분을 색으로 강조할지도 알려주시면 좋겠습니다.
      (예: "소개합니다" -> "소개함니다" 처럼 틀린 부분만 빨갛게)

  (4) 잘못 읽은 단어 표시
      단어별로 점수와 오류 유형이 나오므로, 대본 위에 색으로 표시할 수 있습니다.
      - 잘못 발음한 단어 / 아예 안 읽고 넘어간 단어를 각각 어떻게 보여줄지
        (색상 구분 등) 정해주세요.

  (5) 피드백 4개 항목 배치
      총평 / 잘한 점 / 개선할 점 / 연습 팁 을 어떤 순서와 형태로 배치할지
      정해주세요. (카드 4개 / 아코디언 / 목록 등)

■ 정리 - 필요한 것
================================================================================

  1. AI 대본 생성 흐름 화면   (업로드 -> 조건 입력 -> 로딩 -> 결과/편집)
  2. 발음 코칭 화면            (하이라이팅 + 단어 목록 + 녹음 UI 4상태)
  3. 평가 결과 / 피드백 화면   (점수 + 원본↔인식 비교 + AI 피드백)

  가장 급한 것은 【요청 1】의 (1) 로딩 방식과 (4) 썸네일 필요 여부입니다.
  이 둘은 서버 작업량이 달라져서, 정해지면 바로 반영하겠습니다.

  기능은 이미 다 만들어져 있어서, 디자인만 나오면 연결은 빠르게 가능합니다.
  궁금한 점 있으시면 편하게 물어봐 주세요. 감사합니다!
