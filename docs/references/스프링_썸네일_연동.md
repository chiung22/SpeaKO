# 슬라이드 미리보기(썸네일) 연동 요청 — 스프링

> AI 서버에서 슬라이드 미리보기 PNG를 생성합니다. **AI 서버 쪽은 동작을 확인했고**,
> 지금은 스프링 DTO에 관련 필드가 없어서 프론트까지 전달되지 않는 상태입니다.
> 아래 두 가지만 부탁드립니다. (2026-08-16 기준, 실제 응답값으로 작성)

---

## AI 서버가 주는 것

### ① 상태와 유무 — 프로젝트 조회 응답에 이미 포함

```
GET /api/projects/{project_id}
```
```jsonc
{ "data": {
    "thumbnail_status": "ready",
    "slides": [
      { "slide_number": 1, "has_thumbnail": true,  "script": "...", "source_content": "..." },
      { "slide_number": 2, "has_thumbnail": true,  ... }
    ]
} }
```

### ② 이미지 — 슬라이드마다 따로

```
GET /api/projects/{project_id}/slides/{slide_number}/thumbnail
```
```
200  image/png   (실측 42KB)
Cache-Control: public, max-age=86400
```

JSON이 아니라 **PNG 바이트 그대로**입니다.

없는 슬라이드를 요청하면 404입니다.
```json
{"detail":"이 슬라이드의 미리보기가 없습니다. (생성 상태: ready)"}
```

## 스프링에서 해주실 것

### ① 이미지 중계 엔드포인트

AI 서버는 외부에 열려 있지 않아(`127.0.0.1:8000`) 프론트가 직접 못 부릅니다.

```java
@GetMapping("/api/presentations/{presentationId}/slides/{slideOrder}/thumbnail")
public ResponseEntity<byte[]> getThumbnail(@PathVariable Long presentationId,
                                           @PathVariable int slideOrder) {
    Presentation p = presentationRepository.findById(presentationId)
            .orElseThrow(() -> new IllegalArgumentException("발표 자료를 찾을 수 없습니다."));

    HttpHeaders headers = new HttpHeaders();
    addApiKeyHeader(headers);

    ResponseEntity<byte[]> res = new RestTemplate().exchange(
            AI_BASE_URL + "/api/projects/" + p.getAiProjectId()
                        + "/slides/" + slideOrder + "/thumbnail",
            HttpMethod.GET, new HttpEntity<>(headers), byte[].class);

    return ResponseEntity.ok()
            .contentType(MediaType.IMAGE_PNG)
            .cacheControl(CacheControl.maxAge(1, TimeUnit.DAYS).cachePublic())
            .body(res.getBody());
}
```

> 캐시 헤더를 그대로 넘겨주시면 좋습니다. 한 번 만든 썸네일은 바뀌지 않아서,
> 브라우저가 하루 동안 재요청하지 않습니다.

### ② DTO에 필드 2개 추가

```java
// PresentationResponseDTO.DetailDTO
private String thumbnailStatus;      // pending | ready | failed | unavailable | skipped

// PresentationResponseDTO.SlideScriptDTO
private boolean hasThumbnail;
```

값은 `getPresentationDetails()` 안에서 AI 서버를 조회해 채우시면 됩니다.

```java
HttpHeaders headers = new HttpHeaders();
addApiKeyHeader(headers);

Map ai = new RestTemplate().exchange(
        AI_BASE_URL + "/api/projects/" + presentation.getAiProjectId(),
        HttpMethod.GET, new HttpEntity<>(headers), Map.class).getBody();
Map data = (Map) ai.get("data");

String thumbnailStatus = (String) data.get("thumbnail_status");

// AI의 slide_number가 스프링의 slideOrder와 같은 값입니다
// (saveScripts에서 slideOrder = slide_number로 저장하고 계십니다).
Map<Integer, Boolean> hasThumb = new HashMap<>();
for (Map s : (List<Map>) data.get("slides")) {
    hasThumb.put(((Number) s.get("slide_number")).intValue(),
                 Boolean.TRUE.equals(s.get("has_thumbnail")));
}

// SlideScriptDTO를 만들 때
.hasThumbnail(hasThumb.getOrDefault(slide.getSlideOrder(), false))
```

## 프론트에 함께 전달해주실 것

### ⚠️ `hasThumbnail`이 `true`인 것만 요청

없는 걸 요청하면 404가 오고 **브라우저가 깨진 이미지 아이콘**을 그립니다.

```jsx
{slides.map(s => s.hasThumbnail
  ? <img src={`/api/presentations/${id}/slides/${s.slideOrder}/thumbnail`} />
  : <PlaceholderBox number={s.slideOrder} />
)}
```

### ⚠️ `pending`이면 다시 물어보기

업로드 직후 응답에는 대개 **`pending`**이 실립니다. 썸네일을 기다리느라 업로드 응답을
붙잡지 않기 때문입니다. **2초 간격 폴링이면 충분합니다** — PPTX 18장이 4초면 끝납니다(실측).

| `thumbnailStatus` | 뜻 | 화면 |
|---|---|---|
| `pending` | 만드는 중 | **폴링** — 스켈레톤/로딩 |
| `ready` | 완료 | 이미지 표시 |
| `failed` | 변환 실패 | 자리표시자 (재시도 버튼 불필요) |
| `unavailable` | 서버에 변환 도구 없음 | 자리표시자 |
| `skipped` | 대본만 올린 프로젝트 | **정상** — 그릴 슬라이드가 없음 |

**`pending`만 다시 물어보면 됩니다.** 나머지 넷은 최종 상태입니다.
