# 스프링 연동 체크리스트 — 이 문서 하나만 보시면 됩니다

> 배포된 스프링 JAR(2026-08-14)을 `javap`으로 뜯어 **실제로 호출하는 엔드포인트**를
> 확인하고, PM이 정한 우선순위 순으로 정리했습니다. AI 서버 쪽은 전부 동작 확인이
> 끝난 상태입니다(프로덕션 스모크 9/9 통과, 2026-08-16).
>
> 공통: 모든 AI 호출에 `X-API-Key` 헤더가 필요합니다. `AI_BASE_URL`은 `http://localhost:8000`.

## 현재 상태 한눈에

스프링이 지금 부르고 있는 AI 엔드포인트는 **5개뿐**입니다.

```
✅ POST /api/projects           ✅ POST /api/script/full
✅ GET  /api/script/jobs/{id}   ✅ POST /api/script/partial
✅ POST /api/evaluation/audio
```

| 우선순위 | 기능 | 스프링 | 필요한 작업 |
|---|---|---|---|
| 1 | 대본 생성 결과 | ✅ 됨 | 없음 |
| 2 | **하이라이팅** | ❌ **호출 없음** | §2 |
| 3 | **상세 피드백** | ❌ **호출 없음** | §3 |
| 4 | **다운로드** | ❌ **호출 없음** | §4 |
| — | 슬라이드 미리보기 | ❌ 호출 없음 | §5 |
| — | 발음 듣기(TTS) | ❌ 호출 없음 | §6 |

## §1. 대본 생성 — 이미 되고 있습니다

손대실 것 없습니다. 다만 두 가지만 참고해주세요.

**커스텀 대본(파일/수기 텍스트)은 별도 엔드포인트가 없습니다.** 기존 `POST /api/projects`가
그대로 처리합니다.

| 경우 | 보낼 것 |
|---|---|
| 수기 텍스트 | `script_text` = 대본 전문 (**`text` 아님**) |
| 대본 파일(docx/txt/pdf) | `file` + **`mode=coaching`** |
| PPT/PDF 발표자료 | `file` (`mode` 생략) |

`mode=coaching`을 빼면 발표자료로 보고 슬라이드를 뽑으려 합니다.

**전체 대본이 필요하면** `GET /api/projects/{id}` 응답의 **`full_script`** 를 쓰세요.
직접 이어붙이실 거면 `"Slide 1:"` 같은 라벨을 붙이지 마세요 — 그 텍스트가
`reference_text`로 되돌아오면 라벨까지 채점 대상이 됩니다.

## §2. 하이라이팅 (우선순위 2) — 호출을 추가해주세요

발음 주의 단어를 대본 위에 색칠하는 기능입니다. **AI 서버 호출이 아예 없습니다.**

### ① 분석 실행 — 대본이 확정된 뒤 한 번

```java
Map<String, Object> body = Map.of("project_id", presentation.getAiProjectId());
restTemplate.postForEntity(AI_BASE_URL + "/api/analysis/words",
        new HttpEntity<>(body, jsonHeaders()), Map.class);
```
> 대본 생성 직후에 부르시면 됩니다. 대본을 수정하면 다시 부르셔야 최신 결과가 됩니다.

### ② 결과 읽기

`GET /api/projects/{project_id}` 응답의 **`difficult_words`** 에 들어 있습니다.
(①의 응답 `data.words`에도 같은 값이 있어서, 직후라면 한 번만 불러도 됩니다.)

```jsonc
{
  "word": "책임",
  "standard_pronunciation": "채김",
  "category": "연음",                    // 화면 표시용 (한국어)
  "category_code": "LIAISON",            // ← enum 변환용
  "rule_desc": "연음: 앞 받침이 뒤 모음으로 넘어가 발음됩니다.",
  "occurrences": [
    { "slide_number": 1, "position_start": 4,  "position_end": 6 },
    { "slide_number": 2, "position_start": 11, "position_end": 13 }
  ]
}
```

`PronunciationHighlight` 필드와 이렇게 대응합니다.

| 엔티티 필드 | 쓸 값 |
|---|---|
| `word` | `word` |
| `standardPronunciation` | `standard_pronunciation` |
| `category` | **`category_code`** ← 아래 주의 |
| `ruleDesc` | `rule_desc` |
| `positionStart` / `positionEnd` | `occurrences[]` 안의 값 |

### ⚠️ `category`가 아니라 `category_code`

지금 코드가 `HighlightCategory.valueOf(categoryStr.toUpperCase())`인데, `category`는
**한국어**(`"장단음"`, `"연음"`, `"표기-발음불일치"`)입니다. 한글엔 대문자가 없어서
`valueOf`가 **항상 예외**를 던지고 catch의 기본값으로 떨어집니다 — **세 카테고리 색이
전부 같아집니다.**

| `category` (화면용) | `category_code` (enum용) |
|---|---|
| 장단음 | `LENGTH` |
| 연음 | `LIAISON` |
| 표기-발음불일치 | `MISMATCH` |

### ⚠️ `occurrences`는 배열입니다

한 단어가 여러 번 나오면 자리도 여러 개입니다. `PronunciationHighlight`는 한 행에
좌표가 하나이므로 **occurrence 하나당 한 행**으로 저장하세요.

```java
for (Map<String,Object> occ : (List<Map<String,Object>>) w.get("occurrences")) {
    PronunciationHighlight.builder()
        .script(scriptOfSlide(((Number) occ.get("slide_number")).intValue()))
        .word((String) w.get("word"))
        .standardPronunciation((String) w.get("standard_pronunciation"))
        .category(HighlightCategory.valueOf((String) w.get("category_code")))
        .ruleDesc((String) w.get("rule_desc"))
        .positionStart(((Number) occ.get("position_start")).intValue())
        .positionEnd(((Number) occ.get("position_end")).intValue())
        .build();
}
```

좌표는 **그 슬라이드 대본 문자열 기준**입니다(전체 대본 기준 아님).

## §3. 상세 피드백 (우선순위 3) — 호출을 추가해주세요

`Evaluation.feedbackDetail` 칸이 항상 비어 있는 이유입니다. **부르는 곳이 없습니다.**

**음성 파일을 다시 보낼 필요가 없습니다.** 평가할 때 단어별 점수를 저장해뒀기 때문에
평가 번호 하나만 있으면 됩니다.

```java
// 바디 없음
ResponseEntity<Map> res = restTemplate.postForEntity(
        AI_BASE_URL + "/api/evaluation/" + aiEvaluationId + "/feedback",
        new HttpEntity<>(jsonHeaders()), Map.class);
Map data = (Map) res.getBody().get("data");
```

```jsonc
{ "success": true, "evaluation_id": 12, "cached": false,
  "data": {
    "summary": "총평 2~3문장",
    "strengths": ["잘한 점 1~3개"],
    "improvements": ["개선할 점 1~3개"],
    "practice_tips": [ { "key": "consonant", "title": "명확한 자음", "description": "..." } ],
    "deductions": { "factors": [ { "label": "긴 멈춤", "message": "0.7초 이상 끊긴 구간이 14번…" } ] }
  } }
```

- `evaluation_id`는 **AI 서버가 발급한 번호**입니다. `POST /api/evaluation/audio` 응답의
  `evaluation_id`를 `Evaluation` 엔티티에 같이 저장해두셔야 나중에 부를 수 있습니다.
- `cached: true`면 이전에 만든 걸 그대로 돌려준 것입니다(재호출해도 요금이 안 듭니다).
- `deductions.factors[].message`는 **"왜 점수가 깎였는지"** 를 서버가 완성된 문장으로
  써 둔 값입니다. 화면에 그대로 띄우시면 됩니다.

**응답 시간은 6~7초**입니다(실측). 평가 직후 자동으로 부르실지, 사용자가 "상세 피드백"을
눌렀을 때 부르실지는 화면 흐름에 맞춰 정하시면 됩니다.

## §4. 다운로드 (우선순위 4) — 중계만 해주시면 됩니다

```
GET /api/projects/{project_id}/script.docx       → 대본 docx
GET /api/projects/{project_id}/highlight.docx    → 발음 주의 단어에 색칠한 docx
```

JSON이 아니라 **docx 바이트**입니다. `Content-Disposition: attachment`가 붙어 있습니다.
실측 크기는 각각 41KB / 42KB.

```java
@GetMapping("/api/presentations/{presentationId}/script.docx")
public ResponseEntity<byte[]> downloadScript(@PathVariable Long presentationId) {
    Presentation p = presentationRepository.findById(presentationId).orElseThrow();
    ResponseEntity<byte[]> res = restTemplate.exchange(
            AI_BASE_URL + "/api/projects/" + p.getAiProjectId() + "/script.docx",
            HttpMethod.GET, new HttpEntity<>(apiKeyHeaders()), byte[].class);
    return ResponseEntity.ok()
            .headers(res.getHeaders())      // Content-Disposition 그대로 넘기기
            .body(res.getBody());
}
```

파일명은 **프로젝트명**으로 나갑니다.

## §6. 발음 듣기 (TTS)

발음 주의 단어를 클릭하면 **그 단어의 표준 발음**을 들려주는 기능입니다.
(전체 대본을 읽어주는 기능은 없습니다)

```
POST /api/tts/word     { "word": "책임", "project_id": 16 }   → MP3 바이트
GET  /api/tts/voices                                          → 화자 목록
```

`project_id`를 같이 보내면 `/api/analysis/words`가 저장해둔 발음기호를 찾아 씁니다.
화자는 4명(동현·대성·혜리·고은), 속도는 -5~+5입니다.

docx와 마찬가지로 **바이트를 그대로 중계**하시면 됩니다.

## 그 밖에 — 급하지 않은 것

### 부분 녹음 기준 대본

`EvaluationService`가 `project_id`와 `audio_file`만 보냅니다. **전체 대본을 통째로
녹음하는 구조라면 지금 그대로가 맞습니다.** 슬라이드별 녹음을 넣으실 때만
`slide_number` 또는 `reference_text` 중 하나를 추가하시면 됩니다.

### 발표 습관 지표 (`speech_metrics`)

`Evaluation`에 `fillerWordCount` / `pauseScore` 컬럼이 있는데 `AiEvaluationResponseDto`에
받을 필드가 없어 항상 null입니다. **현재 우선순위 밖이라 급하지 않습니다.**
쓰실 거면 `@JsonProperty("speech_metrics")` 필드를 추가하시면 됩니다.

### 확인 완료된 것 (손대실 필요 없음)

- **`ai_project_id`** — 저장 코드 정상입니다. `Map.get("project_id")` → `Number.longValue()`로
  안전하게 처리하고 계십니다.
- **`grades`** — AI 서버에서 등급(A~F)을 없애고 0~100 정수만 보냅니다. `Float`로 받고
  계시니 그대로 두시면 됩니다.
- **어투(`Tone`)** — `formal`/`casual` 소문자가 AI 서버와 일치합니다.
- **`AiPresentationResponseDto`** — 아무 데서도 쓰이지 않는 죽은 코드입니다. 지우셔도 됩니다.

> ⚠️ `EvaluationService`의 `AI_BASE_URL` 기본값이 죽은 Cloudflare 터널
> (`losing-charity-floyd-transparent.trycloudflare.com`, DNS 해석 안 됨)입니다.
> 지금은 환경변수가 덮고 있어 문제없지만, 환경변수 없이 뜨면 **조용히 전부 실패**합니다.
> 기본값을 `http://localhost:8000`으로 바꿔두시는 편이 안전합니다.
