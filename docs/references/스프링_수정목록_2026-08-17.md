> **2026-08-17 07:38에 EC2에 배포된 JAR**을 `javap`으로 뜯어 확인한 내용입니다.

> AI 서버 쪽은 전부 동작 확인이 끝났습니다(프로덕션 스모크 9/9 통과).

| 부르고 있는 주소 | 실제 주소 | 어느 파일 |
|---|---|---|
| `/api/project/create-custom` | **`/api/projects`** | `EvaluationService`, `PresentationService` |
| `/api/tts/synthesize` | **`/api/tts/word`** | `AudioService` |
| `/api/project/{id}/highlights` | **`/api/analysis/words`** | `PresentationService` |

파라미터 이름도 다릅니다. 아래에 파일별로 적었습니다.

## 1. `EvaluationService.java`

### 1-1. `AI_BASE_URL` 기본값 — **1줄, 제일 먼저**

```java
// 현재
System.getenv().getOrDefault("AI_BASE_URL",
        "https://losing-charity-floyd-transparent.trycloudflare.com");

// 바꿔주세요
System.getenv().getOrDefault("AI_BASE_URL", "http://localhost:8000");
```

저 Cloudflare 주소는 **DNS 해석조차 안 됩니다**(확인함). 지금은 EC2 환경변수가 덮고
있지만, **환경변수 없이 재시작되면 AI 연동이 통째로 조용히 실패합니다.**
데모 당일 재시작 한 번이면 끝입니다.

### 1-2. 커스텀 대본 등록 주소 — `generateAiProjectIdForCustom()`

```java
// 현재 — 없는 주소입니다
AI_BASE_URL + "/api/project/create-custom"
body.add("file", ...);
body.add("text", scriptText);          // ← 파라미터 이름도 다름

// 바꿔주세요
AI_BASE_URL + "/api/projects"
// 파일일 때
body.add("file", ...);
body.add("mode", "coaching");          // ← 이거 없으면 PPT로 보고 슬라이드를 뽑으려 합니다
// 수기 텍스트일 때
body.add("script_text", scriptText);   // ← "text" 아님
```

응답은 PPT 업로드와 **완전히 같습니다.**
```jsonc
{ "success": true, "project_id": 16, "data": { "slides": [ ... ] } }
```

> `AiProjectResponseDto`를 따로 만드실 필요 없습니다. `PresentationService.createAiProject()`가
> 이미 `Map`으로 받아 `project_id`를 꺼내고 있으니 그 방식을 그대로 쓰시면 됩니다.

### 1-3. `evaluation_id` 저장 — **오늘 안에**

```java
// evaluateVoice() 안, Evaluation.builder()에 추가
.aiEvaluationId(aiResult.getEvaluationId())   // DTO에 @JsonProperty("evaluation_id") 이미 있음
```

**왜 오늘인가.** 상세 피드백(§1-4)을 부르려면 이 번호가 필요한데, 지금 저장을 안 하면
**오늘부터 쌓이는 평가도 전부 피드백을 못 받습니다.** 구현은 나중에 하셔도 되지만
저장만은 먼저 시작해두셔야 그때 쓸 데이터가 있습니다.

→ `Evaluation` 엔티티에 `aiEvaluationId` 컬럼 추가 필요 (아래 3번).

### 1-4. 상세 피드백 호출 — **부르는 곳이 아예 없습니다**

`Evaluation.feedbackDetail`이 항상 비어 있는 이유입니다.
**음성 파일을 다시 보낼 필요 없습니다.** 평가 번호만 있으면 됩니다.

```java
// 바디 없음
ResponseEntity<Map> res = restTemplate.postForEntity(
        AI_BASE_URL + "/api/evaluation/" + evaluation.getAiEvaluationId() + "/feedback",
        new HttpEntity<>(headers), Map.class);
Map data = (Map) res.getBody().get("data");
```
```jsonc
{ "data": {
    "summary": "총평 2~3문장",
    "strengths": ["잘한 점"], "improvements": ["개선할 점"],
    "practice_tips": [ { "key": "consonant", "title": "명확한 자음", "description": "..." } ],
    "deductions": { "factors": [ { "label": "긴 멈춤", "message": "0.7초 이상 끊긴 구간이 14번…" } ] }
} }
```

- 응답 시간 **6~7초**(실측)
- `cached: true`면 이전에 만든 것 → 재호출해도 요금 안 듭니다
- `deductions.factors[].message`는 **"왜 깎였는지"를 완성된 문장으로** 준 값입니다. 그대로 띄우세요

## 2. `AudioService.java`

### 2-1. `AI_BASE_URL` 기본값 — 1-1과 동일하게

### 2-2. TTS 주소와 파라미터 — **전부 다릅니다**

```java
// 현재 — 없는 주소입니다
AI_BASE_URL + "/api/tts/synthesize"
body: { "text": ..., "voice_style": ..., "speed": ... }
응답에서 "audio_url", "duration"을 꺼내는 중

// 바꿔주세요
AI_BASE_URL + "/api/tts/word"
body: { "word": "책임", "project_id": 16, "voice": "혜리", "speed": 0 }
```

**응답이 JSON이 아닙니다. MP3 바이트가 그대로 옵니다.**
`audio_url`도 `duration`도 없습니다. 받아서 그대로 프론트에 중계하시면 됩니다.

```java
ResponseEntity<byte[]> res = restTemplate.postForEntity(
        AI_BASE_URL + "/api/tts/word", new HttpEntity<>(body, headers), byte[].class);
return ResponseEntity.ok().contentType(MediaType.valueOf("audio/mpeg")).body(res.getBody());
```

- `project_id`를 같이 보내면 저장해둔 발음기호를 찾아 씁니다(더 정확합니다)
- 화자 목록은 `GET /api/tts/voices` — 동현·대성·혜리·고은 4명, 속도 -5~+5
- **전체 대본을 읽어주는 기능은 없습니다.** 단어 단위만 있습니다

## 4. `AiEvaluationResponseDto.java`

`speech_metrics`를 받을 필드가 없어서 `fillerWordCount` / `pauseScore` 컬럼이
**항상 null**입니다. 시연 대사에 *"발표 속도나 음성 관련 지표를 통해 말하기 습관도
확인할 수 있습니다"* 가 있어서, 안 채우면 화면에 없는 걸 말하게 됩니다.

```java
@JsonProperty("speech_metrics")
private SpeechMetrics speechMetrics;

@JsonProperty("deductions")
private Map<String, Object> deductions;      // 상세 피드백 근거

public static class SpeechMetrics {
    @JsonProperty("filler_words")    private Map<String, Object> fillerWords;
    @JsonProperty("pauses")          private Map<String, Object> pauses;
    @JsonProperty("speech_rate_wpm") private Integer speechRateWpm;
}
```

AI 서버가 보내는 실제 값(5분 녹음 실측):
```jsonc
"speech_metrics": {
  "filler_words": { "count": 0, "by_word": [], "spoken_word_count": 491 },
  "pauses": { "count": 14, "total_seconds": 18.68, "longest_seconds": 2.54,
              "items": [ { "after_word": "하겠습니다", "seconds": 1.2 } ] },
  "speech_rate_wpm": 96
}
```

`Grades` 내부 클래스는 **지우셔도 됩니다.** AI 서버에서 등급(A~F)을 없애고 0~100 정수만
보냅니다. `Float`로 받고 계시니 점수 자체는 그대로 들어갑니다.

## 5. `PresentationService.java`

### 5-1. `AI_BASE_URL` 기본값 — 1-1과 동일하게 (여기도 있습니다)

### 5-2. 커스텀 대본 등록 — 1-2와 동일하게

### 5-3. 하이라이팅 — 주소가 없고, 카테고리도 안 맞습니다

```java
// 현재 — 없는 주소입니다
GET  AI_BASE_URL + "/api/project/" + aiProjectId + "/highlights"

// 바꿔주세요 — 두 단계입니다
// ① 분석 실행 (대본이 확정된 뒤 한 번)
POST AI_BASE_URL + "/api/analysis/words"     body: { "project_id": 16 }
// ② 결과 읽기
GET  AI_BASE_URL + "/api/projects/16"        → data.difficult_words
```
①의 응답 `data.words`에도 같은 값이 있어서, 직후라면 한 번만 부르셔도 됩니다.

**응답 형태:**
```jsonc
{
  "word": "책임",
  "standard_pronunciation": "채김",
  "category": "연음",                    // 화면 표시용 (한국어)
  "category_code": "LIAISON",            // ← enum 변환용
  "rule_desc": "연음: 앞 받침이 뒤 모음으로 넘어가 발음됩니다.",
  "occurrences": [
    { "slide_number": 1, "position_start": 4,  "position_end": 6 },
    { "slide_number": 2, "position_start": 11, "position_end": 13 }
  ]
}
```

#### ⚠️ `category`가 아니라 `category_code`를 쓰세요

```java
HighlightCategory.valueOf(categoryStr.toUpperCase())
```
`category`는 **한국어**(`"장단음"`, `"연음"`, `"표기-발음불일치"`)입니다. 한글에는 대문자가
없어서 `valueOf`가 **항상 예외**를 던지고 catch의 기본값으로 떨어집니다 —
**세 카테고리 색이 전부 같아집니다.**

| `category` | `category_code` | enum |
|---|---|---|
| 장단음 | `LENGTH` | ✅ 일치 |
| 연음 | `LIAISON` | ✅ 일치 |
| 표기-발음불일치 | `MISMATCH` | ✅ 일치 |

#### ⚠️ `occurrences`는 배열입니다 — 행을 여러 개 만드세요

한 단어가 대본에 여러 번 나오면 자리도 여러 개입니다.
`PronunciationHighlight`는 한 행에 좌표가 하나니까 **occurrence당 한 행**입니다.

```java
for (Map<String,Object> occ : (List<Map<String,Object>>) w.get("occurrences")) {
    PronunciationHighlight.builder()
        .script(scriptOfSlide(((Number) occ.get("slide_number")).intValue()))
        .word((String) w.get("word"))
        .standardPronunciation((String) w.get("standard_pronunciation"))
        .category(HighlightCategory.valueOf((String) w.get("category_code")))
        .ruleDesc((String) w.get("rule_desc"))
        .positionStart(((Number) occ.get("position_start")).intValue())
        .positionEnd(((Number) occ.get("position_end")).intValue())
        .build();
}
```

좌표는 **그 슬라이드 대본 문자열 기준**입니다(전체 대본 기준 아님).
AI의 `slide_number`는 스프링의 `slideOrder`와 **같은 값**입니다
(`saveScripts()`에서 그렇게 저장하고 계십니다).

### 5-4. 전체 대본은 `full_script`를 쓰세요

`getFullScriptForRecording()`에서 `"\n\n"`으로 직접 이어붙이고 계신데, AI 서버가
이어붙인 값을 줍니다. `GET /api/projects/{id}` 응답의 **`full_script`** 입니다.

직접 이어붙이셔도 되지만 **그 문자열을 `reference_text`로 되보내지는 마세요** —
슬라이드 사이 빈 줄까지 채점 기준에 들어갑니다.

## 7. `PresentationController.java` — 중계 엔드포인트 3종

AI 서버는 `127.0.0.1:8000`으로만 열려 있어 **프론트가 직접 못 부릅니다.**
아래 셋은 전부 **바이트를 그대로 넘기는** 형태입니다.

```java
// ① 썸네일 이미지
@GetMapping("/api/presentations/{presentationId}/slides/{slideOrder}/thumbnail")
→ AI: GET /api/projects/{aiProjectId}/slides/{slideOrder}/thumbnail
   image/png, 실측 42KB, Cache-Control: public, max-age=86400

// ② 대본 docx
@GetMapping("/api/presentations/{presentationId}/script.docx")
→ AI: GET /api/projects/{aiProjectId}/script.docx          (실측 41KB)

// ③ 하이라이팅 docx
@GetMapping("/api/presentations/{presentationId}/highlight.docx")
→ AI: GET /api/projects/{aiProjectId}/highlight.docx        (실측 42KB)
```

```java
ResponseEntity<byte[]> res = restTemplate.exchange(
        AI_BASE_URL + path, HttpMethod.GET, new HttpEntity<>(apiKeyHeaders()), byte[].class);
return ResponseEntity.ok().headers(res.getHeaders()).body(res.getBody());
```

docx는 `Content-Disposition: attachment`가 붙어 있으니 헤더를 그대로 넘기시면
파일명(프로젝트명)까지 살아납니다.

## 8. `AiPresentationResponseDto.java` — 지우셔도 됩니다

`presentationId` / `message` 필드를 가지고 있는데 AI 서버는 그런 필드를 보내지 않습니다.
확인해보니 **아무 데서도 쓰이지 않는 죽은 코드**입니다. 실제 저장 경로는
`PresentationService.createAiProject()`이고 그쪽은 정상입니다.

남겨두면 다음에 누가 "이게 파싱하는 줄" 알고 헛짚습니다.

## 손대실 필요 없는 것 (확인 완료)

- **`ai_project_id` 저장** — 정상입니다. `Map.get("project_id")` → `Number.longValue()`로
  안전하게 처리하고 계십니다.
- **어투(`Tone`)** — `formal` / `casual` 소문자가 AI 서버와 일치합니다.
- **점수 타입** — 엔티티가 `Float`라 정수 `87`이 `87.0f`로 그대로 들어갑니다.
- **`WordDetail`** — `reference_span` / `recognized_span`까지 이미 매핑돼 있습니다.
  평가 결과 하이라이팅은 이것만으로 그릴 수 있습니다.
- **부분 녹음** — 전체 대본을 통째로 녹음하는 구조라면 지금 그대로가 맞습니다.

## 순서 제안

| 순서 | 무엇 | 예상 |
|---|---|---|
| 1 | `AI_BASE_URL` 3곳(§1-1, §2-1, §5-1) + `aiEvaluationId` 저장(§1-3, §3) | 30분 |
| 2 | 없는 주소 3개 교체 (§1-2, §2-2, §5-3) | 1~2시간 |
| 3 | 하이라이팅 저장 로직 (§5-3의 `category_code` / `occurrences`) | 반나절 |
| 4 | 상세 피드백 + 습관 지표 (§1-4, §4) | 1~2시간 |
| 5 | 썸네일 (§5-5, §6, §7①) | 30분 |
| 6 | 다운로드 (§7②③) | 30분 |

**1번이 제일 급합니다.** 1줄짜리 수정이 데모 당일 사고를 막고, `aiEvaluationId`는
지금 저장을 시작해야 나중에 쓸 데이터가 쌓입니다.
