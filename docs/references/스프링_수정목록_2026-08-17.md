## 1-2. `generateAiProjectIdForCustom()` — 메서드 통째로 교체

주소도 파라미터도 다릅니다. 아래로 바꿔주세요.

```java
/**
 * 커스텀 대본(파일 또는 수기 텍스트)을 AI 서버에 등록하고 project_id를 받아온다.
 * ⚠️ 별도 엔드포인트가 없다. PPT 업로드와 같은 POST /api/projects를 쓴다.
 */
private Long generateAiProjectIdForCustom(String scriptText, MultipartFile scriptFile) {
    RestTemplate restTemplate = new RestTemplate();
    SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();
    factory.setConnectTimeout(10_000);
    factory.setReadTimeout(30_000);
    restTemplate.setRequestFactory(factory);

    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.MULTIPART_FORM_DATA);
    addApiKeyHeader(headers);

    MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();

    if (scriptFile != null && !scriptFile.isEmpty()) {
        // 완성된 대본 파일(docx/txt/pdf)
        final byte[] fileBytes;
        try {
            fileBytes = scriptFile.getBytes();
        } catch (IOException e) {
            throw new RuntimeException("대본 파일 읽기 실패", e);
        }
        final String filename = scriptFile.getOriginalFilename() != null
                ? scriptFile.getOriginalFilename() : "script.txt";

        body.add("file", new ByteArrayResource(fileBytes) {
            @Override public String getFilename() { return filename; }
        });
        // ⚠️ 이게 없으면 발표자료(PPT)로 보고 슬라이드를 뽑으려 한다
        body.add("mode", "coaching");

    } else if (scriptText != null && !scriptText.isBlank()) {
        // 수기 텍스트  ⚠️ 파라미터 이름이 "text"가 아니라 "script_text"
        body.add("script_text", scriptText);

    } else {
        throw new IllegalArgumentException("대본 파일이나 텍스트 중 하나는 반드시 존재해야 합니다.");
    }

    try {
        ResponseEntity<Map> response = restTemplate.postForEntity(
                AI_BASE_URL + "/api/projects",           // ⚠️ /api/project/create-custom 아님
                new HttpEntity<>(body, headers),
                Map.class);

        Map responseBody = response.getBody();
        if (responseBody == null || !(responseBody.get("project_id") instanceof Number)) {
            throw new IllegalStateException("AI 서버 응답에 project_id가 없습니다: " + responseBody);
        }
        return ((Number) responseBody.get("project_id")).longValue();

    } catch (HttpStatusCodeException e) {
        throw new ResponseStatusException(e.getStatusCode(),
                "AI 서버 프로젝트 생성 실패: " + extractDetail(e.getResponseBodyAsString()));
    }
}
```

**응답은 PPT 업로드와 완전히 같습니다.**
```jsonc
{ "success": true, "project_id": 16,
  "data": { "metadata": {...}, "slides": [ { "slide_number": 1, "content": "..." } ] } }
```
대본만 올린 경우 **슬라이드 1번에 전체 대본이 한 덩어리**로 들어갑니다.

## 1-4. 상세 피드백 호출 — 메서드 새로 추가

`Evaluation.feedbackDetail`이 항상 비어 있는 이유입니다. **부르는 곳이 아예 없습니다.**

**음성 파일을 다시 보낼 필요 없습니다.** 평가할 때 단어별 점수를 저장해뒀기 때문에 평가 번호 하나면 됩니다.

```java
/**
 * AI 서버에 상세 피드백을 요청해 Evaluation에 저장한다.
 * 바디 없음. 응답 6~7초(실측). cached=true면 이전 결과라 추가 요금이 없다.
 */
@Transactional
public Map<String, Object> generateFeedback(Long evaluationId) {
    Evaluation evaluation = evaluationRepository.findById(evaluationId)
            .orElseThrow(() -> new IllegalArgumentException("평가 결과를 찾을 수 없습니다."));

    Long aiEvaluationId = evaluation.getAiEvaluationId();
    if (aiEvaluationId == null) {
        throw new IllegalStateException(
                "이 평가에는 AI 평가 번호가 없습니다. (aiEvaluationId 도입 전 데이터 — 다시 녹음해주세요)");
    }

    RestTemplate restTemplate = new RestTemplate();
    SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();
    factory.setConnectTimeout(10_000);
    factory.setReadTimeout(120_000);          // 피드백 생성은 6~7초지만 넉넉히
    restTemplate.setRequestFactory(factory);

    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.APPLICATION_JSON);
    addApiKeyHeader(headers);

    Map<String, Object> data;
    try {
        ResponseEntity<Map> res = restTemplate.postForEntity(
                AI_BASE_URL + "/api/evaluation/" + aiEvaluationId + "/feedback",
                new HttpEntity<>(headers),     // 바디 없음
                Map.class);
        Map body = res.getBody();
        if (body == null || body.get("data") == null) {
            throw new IllegalStateException("AI 서버가 피드백을 주지 않았습니다: " + body);
        }
        data = (Map<String, Object>) body.get("data");

    } catch (HttpStatusCodeException e) {
        throw new ResponseStatusException(e.getStatusCode(),
                extractDetail(e.getResponseBodyAsString()));
    }

    try {
        evaluation.updateFeedbackDetail(objectMapper.writeValueAsString(data));
        evaluationRepository.save(evaluation);
    } catch (Exception e) {
        throw new RuntimeException("피드백 저장 실패", e);
    }
    return data;
}
```

**응답 예시:**
```jsonc
{ "success": true, "evaluation_id": 12, "cached": false,
  "data": {
    "summary": "총평 2~3문장",
    "strengths": ["잘한 점 1~3개"],
    "improvements": ["개선할 점 1~3개"],
    "practice_tips": [ { "key": "consonant", "title": "명확한 자음", "description": "..." } ],
    "deductions": { "factors": [
        { "label": "긴 멈춤", "message": "0.7초 이상 말이 끊긴 구간이 14번 있었습니다(가장 긴 구간 2.54초)." },
        { "label": "부정확한 발음", "message": "33개 단어가 정확도 70점 미만이었습니다(말한 단어의 6.7%)." }
    ] } } }
```

`deductions.factors[].message`는 **"왜 깎였는지"를 서버가 완성된 문장으로 써 둔 값**입니다. 화면에 그대로 띄우시면 됩니다.

## 2-2. TTS 호출 — 주소·파라미터·응답이 **전부** 다릅니다

```java
// 현재
AI_BASE_URL + "/api/tts/synthesize"
body:  { "text": ..., "voice_style": ..., "speed": ... }
응답에서 "audio_url", "duration" 을 꺼내는 중   ← 그런 필드가 없습니다
```

**응답이 JSON이 아니라 MP3 바이트입니다.** 아래로 바꿔주세요.

```java
/**
 * 단어 하나의 표준 발음을 MP3로 받아 그대로 돌려준다.
 * ⚠️ 응답은 JSON이 아니라 audio/mpeg 바이트다. audio_url도 duration도 없다.
 */
public byte[] synthesizeWord(Long presentationId, String word, String voice, Integer speed) {
    Presentation p = presentationRepository.findById(presentationId)
            .orElseThrow(() -> new IllegalArgumentException("존재하지 않는 발표 자료입니다."));

    if (word == null || word.isBlank()) {
        throw new IllegalArgumentException("음성으로 변환할 단어 텍스트가 없습니다.");
    }

    RestTemplate restTemplate = new RestTemplate();
    SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();
    factory.setConnectTimeout(10_000);
    factory.setReadTimeout(30_000);
    restTemplate.setRequestFactory(factory);

    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.APPLICATION_JSON);
    addApiKeyHeader(headers);

    Map<String, Object> body = new HashMap<>();
    body.put("word", word);
    body.put("project_id", p.getAiProjectId());   // 저장된 발음기호를 찾아 쓴다 (더 정확)
    if (voice != null && !voice.isBlank()) body.put("voice", voice);
    if (speed != null) body.put("speed", speed);

    try {
        ResponseEntity<byte[]> res = restTemplate.postForEntity(
                AI_BASE_URL + "/api/tts/word",        // ⚠️ /api/tts/synthesize 아님
                new HttpEntity<>(body, headers),
                byte[].class);
        return res.getBody();

    } catch (HttpStatusCodeException e) {
        throw new ResponseStatusException(e.getStatusCode(),
                "AI 음성 합성 실패: " + extractDetail(e.getResponseBodyAsString()));
    }
}
```

**컨트롤러에서는 이렇게 내보내면 됩니다.**

```java
@PostMapping("/api/presentations/{presentationId}/tts/word")
public ResponseEntity<byte[]> ttsWord(@PathVariable Long presentationId,
                                      @RequestBody Map<String, Object> req) {
    byte[] mp3 = audioService.synthesizeWord(
            presentationId,
            (String) req.get("word"),
            (String) req.get("voice"),
            req.get("speed") == null ? null : ((Number) req.get("speed")).intValue());

    return ResponseEntity.ok()
            .contentType(MediaType.valueOf("audio/mpeg"))
            .body(mp3);
}
```

**화자 목록도 중계해주세요.** 프론트가 하드코딩하지 않게 하려고 만든 API입니다.

```java
@GetMapping("/api/tts/voices")
// → AI: GET /api/tts/voices
// { "voices": [ {"name":"동현","gender":"남성"}, ... ], "speed": {"min":-5,"max":5,"default":0} }
```

화자는 **동현·대성·혜리·고은 4명**, 속도는 **-5 ~ +5**(음수가 빠름)입니다.

> **전체 대본을 읽어주는 API는 없습니다.** 단어 단위만 있습니다. Clova Voice가 한국어 음운 규칙을 일부만 적용해서, 철자를 그대로 넣으면 틀린 발음이 나가기 때문입니다(`각자`→[각자], `책임`→[책임]). 그래서 서버가 G2P로 만든 발음 문자열을 단어마다 넣습니다.

| 엔티티 필드 | DB 컬럼 | 상태 |

### `ai_evaluation_id` — 대개 SQL이 필요 없습니다

`presentations` 테이블을 보면 `file_url`, `ai_project_id`가 **COMMENT 없이 맨 끝에** 붙어 있습니다. Hibernate `ddl-auto=update`가 만든 흔적입니다. 그렇다면 **엔티티에 필드를 추가하고 재기동하는 것만으로 컬럼이 생깁니다.**

```bash
grep -A3 "ddl-auto" src/main/resources/application*.yml
```

`update`가 아니거나 확실히 하고 싶으면:

```sql
ALTER TABLE evaluations
  ADD COLUMN ai_evaluation_id BIGINT NULL COMMENT 'AI 서버가 발급한 평가 번호';
```

**`NULL` 허용으로 두세요.** 기존 평가 기록에는 이 값이 없습니다.

### ⚠️ `slide_id` — 이쪽이 더 위험합니다

```sql
`slide_id` bigint NOT NULL COMMENT '평가 대상 슬라이드 고유 식별자',
CONSTRAINT `fk_evaluations_slide_id` FOREIGN KEY (`slide_id`) REFERENCES `slides` (`slide_id`)
```

DB는 **슬라이드 단위**로 평가를 저장하는데 엔티티 필드명은 `presentationId`입니다.

- `@Column(name = "slide_id")`가 붙어 있으면 → 정상, 이름만 다른 것
- 안 붙어 있으면 → `ddl-auto=update`가 `presentation_id`를 새로 만들고 **`slide_id NOT NULL`은 그대로 남습니다.** 평가 저장마다 실패합니다:

```
Field 'slide_id' doesn't have a default value
```

후자면:
```sql
ALTER TABLE evaluations MODIFY COLUMN slide_id BIGINT NULL;
```

## 💡 `pronunciation_highlights` — 이미 있는데 비어 있습니다

이 테이블은 AI 서버가 주는 발음 주의 단어와 **필드가 1:1로 맞습니다.** 새로 만들 것이 없습니다.

```sql
script_id, word, standard_pronunciation,
category enum('mismatch','liaison','length'),
rule_desc, position_start, position_end
```

`GET /api/projects/{id}` 응답의 `difficult_words[]`와 매핑:

| DB 컬럼 | AI 응답 | 변환 |
|---|---|---|
| `word` | `word` | 그대로 |
| `standard_pronunciation` | `standard_pronunciation` | 그대로 |
| `category` | `category_code` | **`.toLowerCase()`** — DB enum이 소문자 |
| `rule_desc` | `rule_desc` | 그대로 |
| `position_start` / `position_end` | `occurrences[].position_start` / `_end` | 그대로 |
| `script_id` | `occurrences[].slide_number` | slide_number → 그 슬라이드의 `script_id`로 변환 |

**`occurrences`는 배열입니다.** 같은 단어가 여러 번 나오면 **행이 여러 개** 생깁니다 (실측: 단어 16개 → 149행). 오프셋은 **해당 슬라이드 대본 안에서의 위치**이지 전체 대본 기준이 아닙니다. 자세한 내용은 §5-3.

## 참고 — `recognized_text`에 섞여 있던 "Slide"는 고쳤습니다

덤프의 평가 1번 인식 텍스트에 `Slide`가 반복해서 끼어 있습니다. AI 서버가 채점 기준 텍스트에 `"Slide 1: "` 라벨을 붙여 넘기던 버그였고 **2026-08-16에 수정·배포**했습니다. 지금 다시 평가하면 나오지 않습니다.

# 4. `AiEvaluationResponseDto.java`

`speech_metrics`를 받을 필드가 없어 `fillerWordCount` / `pauseScore` 컬럼이 **항상 null**입니다.

시연 대사에 *"발표 속도나 음성 관련 지표를 통해 말하기 습관도 확인할 수 있습니다"* 가 있어서, 안 채우면 **화면에 없는 걸 말하게 됩니다.**

```java
@JsonProperty("speech_metrics")
private SpeechMetrics speechMetrics;

@JsonProperty("deductions")
private Map<String, Object> deductions;

@JsonProperty("highlights")
private Map<String, Object> highlights;   // 선택 — words_detail로도 그릴 수 있음

@Getter @Setter @NoArgsConstructor
```

## 5-3. `requestAndSaveHighlights()` — 메서드 통째로 교체

주소가 없고, 카테고리 변환도 항상 실패합니다.

```java
// 현재 — 없는 주소입니다
GET AI_BASE_URL + "/api/project/" + aiProjectId + "/highlights"
```

**두 단계로 나뉩니다.**

```java
/**
 * AI 서버에 발음 주의 단어 분석을 요청하고 하이라이트를 저장한다.
 * ① POST /api/analysis/words 로 분석 실행
 * ② 응답의 data.words 를 그대로 저장 (GET /api/projects/{id} 의 difficult_words 와 같은 값)
 */
@SuppressWarnings("unchecked")
private void requestAndSaveHighlights(Long aiProjectId, Map<Integer, Script> scriptsBySlideOrder) {
    RestTemplate restTemplate = new RestTemplate();
    SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();
    factory.setConnectTimeout(10_000);
    factory.setReadTimeout(120_000);        // 사전 조회가 있어 10초 안팎 걸린다
    restTemplate.setRequestFactory(factory);

    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.APPLICATION_JSON);
    addApiKeyHeader(headers);

    Map<String, Object> reqBody = new HashMap<>();
    reqBody.put("project_id", aiProjectId);

    Map responseBody;
    try {
        responseBody = restTemplate.postForEntity(
                AI_BASE_URL + "/api/analysis/words",      // ⚠️ 주소 변경
                new HttpEntity<>(reqBody, headers),
                Map.class).getBody();
    } catch (HttpStatusCodeException e) {
        throw new ResponseStatusException(e.getStatusCode(),
                extractDetail(e.getResponseBodyAsString()));
    }

    Map<String, Object> data = responseBody == null
            ? null : (Map<String, Object>) responseBody.get("data");
    if (data == null || data.get("words") == null) {
        throw new IllegalStateException("AI 서버가 분석 결과를 주지 않았습니다: " + responseBody);
    }

    for (Map<String, Object> w : (List<Map<String, Object>>) data.get("words")) {

        // ⚠️ category(한국어)가 아니라 category_code(영문)를 쓴다. 아래 설명 참고.
        HighlightCategory category;
        try {
            category = HighlightCategory.valueOf((String) w.get("category_code"));
        } catch (IllegalArgumentException | NullPointerException e) {
            System.err.println("알 수 없는 카테고리: " + w.get("category_code") + " — 건너뜁니다.");
            continue;
        }

        // ⚠️ occurrences 는 배열이다. 한 단어가 여러 번 나오면 행도 여러 개.
        List<Map<String, Object>> occurrences =
                (List<Map<String, Object>>) w.getOrDefault("occurrences", List.of());

        for (Map<String, Object> occ : occurrences) {
            int slideOrder = ((Number) occ.get("slide_number")).intValue();
            Script script = scriptsBySlideOrder.get(slideOrder);
            if (script == null) continue;      // 그 슬라이드의 대본이 없으면 건너뛴다

            pronunciationHighlightRepository.save(
                PronunciationHighlight.builder()
                    .script(script)
                    .word((String) w.get("word"))
                    .standardPronunciation((String) w.get("standard_pronunciation"))
                    .category(category)
                    .ruleDesc((String) w.get("rule_desc"))
                    .positionStart(((Number) occ.get("position_start")).intValue())
                    .positionEnd(((Number) occ.get("position_end")).intValue())
                    .build());
        }
    }
}
```

**응답 형태:**
```jsonc
{
  "word": "책임",
  "phoneme": "[채김]",
  "standard_pronunciation": "채김",
  "category": "연음",                    // 화면 표시용 (한국어)
  "category_code": "LIAISON",            // ← enum 변환용
  "description": "연음: 앞 받침이 뒤 모음으로 넘어가 발음됩니다.",
  "rule_desc": "연음: 앞 받침이 뒤 모음으로 넘어가 발음됩니다.",
  "occurrences": [
    { "slide_number": 1, "position_start": 4,  "position_end": 6 },
    { "slide_number": 2, "position_start": 11, "position_end": 13 }
  ]
}
```

### ⚠️ 왜 `category_code`인가

```java
HighlightCategory.valueOf(categoryStr.toUpperCase())   // 현재 코드
```
`category`는 **한국어**입니다. 한글에는 대문자가 없어서 `toUpperCase()`를 해도 그대로고, `valueOf("장단음")`은 **항상 예외**를 던집니다. 그래서 catch의 기본값으로 떨어져 **세 카테고리 색이 전부 같아집니다.**

| `category` (화면용) | `category_code` | enum |
|---|---|---|
| 장단음 | `LENGTH` | ✅ |
| 연음 | `LIAISON` | ✅ |
| 표기-발음불일치 | `MISMATCH` | ✅ |

### ⚠️ 좌표 기준

`position_start` / `position_end`는 **그 슬라이드 대본 문자열 기준**입니다(전체 대본 기준 아님).
AI의 `slide_number`는 스프링의 `slideOrder`와 **같은 값**입니다 — `saveScripts()`에서 그렇게 저장하고 계십니다.

### 언제 부르나

**대본이 확정된 뒤 한 번**입니다. `callPythonAiServerForScript()`가 끝난 직후, 그리고 사용자가 대본을 수정해 저장한 뒤에 다시 부르시면 됩니다.

# 7. `PresentationController.java` — 중계 3종

AI 서버는 `127.0.0.1:8000`으로만 열려 있어 **프론트가 직접 못 부릅니다.** 셋 다 **바이트를 그대로 넘기는** 형태입니다.

```java
/** ① 슬라이드 미리보기 이미지 */
@GetMapping("/api/presentations/{presentationId}/slides/{slideOrder}/thumbnail")
public ResponseEntity<byte[]> getThumbnail(@PathVariable Long presentationId,
                                           @PathVariable int slideOrder) {
    return relay(presentationId,
            "/slides/" + slideOrder + "/thumbnail",
            MediaType.IMAGE_PNG);
}

/** ② 대본 docx */
@GetMapping("/api/presentations/{presentationId}/script.docx")
public ResponseEntity<byte[]> downloadScript(@PathVariable Long presentationId) {
    return relay(presentationId, "/script.docx", null);
}

/** ③ 하이라이팅 docx */
@GetMapping("/api/presentations/{presentationId}/highlight.docx")
public ResponseEntity<byte[]> downloadHighlight(@PathVariable Long presentationId) {
    return relay(presentationId, "/highlight.docx", null);
}

/** AI 서버의 바이트 응답을 그대로 넘긴다. */
private ResponseEntity<byte[]> relay(Long presentationId, String suffix, MediaType contentType) {
    Presentation p = presentationRepository.findById(presentationId)
            .orElseThrow(() -> new IllegalArgumentException("발표 자료를 찾을 수 없습니다."));

    HttpHeaders headers = new HttpHeaders();
    addApiKeyHeader(headers);

    ResponseEntity<byte[]> res = new RestTemplate().exchange(
            AI_BASE_URL + "/api/projects/" + p.getAiProjectId() + suffix,
            HttpMethod.GET, new HttpEntity<>(headers), byte[].class);

    ResponseEntity.BodyBuilder builder = ResponseEntity.ok();
    if (contentType != null) {
        builder.contentType(contentType)
               .cacheControl(CacheControl.maxAge(1, TimeUnit.DAYS).cachePublic());
    } else {
        // docx는 Content-Disposition(파일명)을 그대로 넘겨야 한다
        builder.headers(res.getHeaders());
    }
    return builder.body(res.getBody());
}
```

**실측 크기** — 썸네일 42KB(PNG), 대본 docx 41KB, 하이라이팅 docx 42KB.
docx 파일명은 **프로젝트명**으로 나갑니다.
