# 남은 1건 — AudioController 발음 듣기 (5분)

### 파일: `src/main/java/com/example/speako/domain/audio/controller/AudioController.java`

**[지금 코드]** — 13:20 빌드:

```java
@RestController
@RequestMapping("/api/audio")
public class AudioController {

    @PostMapping("/tts/highlight")
    public ResponseEntity<byte[]> ttsWord(@PathVariable Long presentationId,
                                          @RequestBody Map<String, Object> req) {
        byte[] mp3 = audioService.synthesizeWord(presentationId, (String) req.get("word"),
                (String) req.get("voice"),
                req.get("speed") == null ? null : ((Number) req.get("speed")).intValue());
        return ResponseEntity.ok().contentType(MediaType.valueOf("audio/mpeg")).body(mp3);
    }
}
```

**문제**: 주소(`/api/audio/tts/highlight`)에 `{presentationId}` 자리가 없는데 파라미터가
`@PathVariable`입니다. 이 주소를 부르면 스프링이 값을 못 찾아 **무조건 500**이 납니다.
(프론트가 아직 TTS를 안 불러서 지금 피해는 없지만, 연동하는 순간 터집니다.)

**[바꾼 코드]** — presentationId를 body에서 받기:

```java
@RestController
@RequestMapping("/api/audio")
public class AudioController {

    @PostMapping("/tts/highlight")
    public ResponseEntity<byte[]> ttsWord(@RequestBody Map<String, Object> req) {
        Long presentationId = ((Number) req.get("presentationId")).longValue();
        byte[] mp3 = audioService.synthesizeWord(presentationId, (String) req.get("word"),
                (String) req.get("voice"),
                req.get("speed") == null ? null : ((Number) req.get("speed")).intValue());
        return ResponseEntity.ok().contentType(MediaType.valueOf("audio/mpeg")).body(mp3);
    }
}
```

### 프론트에 알려줄 계약 (확정)

```
POST /api/audio/tts/highlight
body: { "presentationId": 57, "word": "책임", "voice": "혜리"(선택), "speed": 0(선택) }
응답: MP3 바이트 (audio/mpeg) — JSON 아님
```

프론트는 blob으로 받아 재생: `new Audio(URL.createObjectURL(await res.blob())).play()`
화자 4명(동현·대성·혜리·고은), 속도 -5~+5(음수가 빠름). 목록: `GET /api/tts/voices`
